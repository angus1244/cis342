# AI 編輯紀錄（`lpr_dev.ipynb`）

> **用途**：記錄「每一次由 AI 執行」對 `notebooks/lpr_dev.ipynb` 的修改，用來回答「這個 cell 是誰改的、什麼時候改的、為什麼改」。
>
> **重要**：本檔**不會**提交給評閱老師，也不屬於 notebook 內容。它是開發期輔助紀錄。
>
> **範圍**：只記 `lpr_dev.ipynb`。`TASK_DIVISION.md`、口頭討論、其他檔案不在此列。

## 紀錄規則

1. **每一次 AI 修改 notebook，就新增一筆**，追加在檔案最下方（時間由舊到新）。
2. 每一筆必須包含：
   - `時間`、`Commit`（該筆修改對應的 git commit hash，7 碼即可）
   - `修改範圍`：受影響的 cell 編號與標題（**改完之後**的編號）
   - `為什麼改`：使用者的原始要求（一句話，盡量貼近原話）
   - `改了什麼`：具體動作（新增／覆寫／刪除／重排）
3. `Commit` 欄若為 `—`，代表該筆修改尚未 commit。
4. 使用者本人手動修改的部分**不需要**記錄在此（由 git 本身的 diff 呈現即可）。

## 為什麼要兩套紀錄並用

| | 回答什麼問題 | 弱點 |
|---|---|---|
| **git commit** | 「當時的檔案長什麼樣」— 真實內容，可完整還原 | notebook 是 JSON，diff 看不出意圖；執行 notebook 會產生與本次修改無關的 output 變動 |
| **本檔（log）** | 「為什麼改、改在哪個 cell」— 意圖與範圍 | 純文字，無法還原內容；可能與實際狀態不一致 |

兩者並用：本檔記**意圖**，git 記**事實**，並用 `Commit` 欄互相對應。
